# Проверки в самом Foundry

Стенд (`dev/harness/`) имитирует Foundry, поэтому три вещи можно проверить только в настоящем
мире v14. Понадобятся ведущий и два игрока в разных браузерах (или в окнах инкогнито).

## 1. Личный запрос доходит только адресату

От этого зависит, скрыты ли по-настоящему чужие кости в «Костях лжеца».

**Игрок Б** (наблюдатель) — в консоли браузера (F12):

```js
game.socket.onAny((event, ...args) => {
  if (JSON.stringify(args).includes("tavern-spike")) console.warn("УТЕЧКА: вижу чужой запрос", event, args);
});
```

**Игрок А** (адресат) — в консоли:

```js
CONFIG.queries["ssl_tavern_games.spike"] = (...args) => { console.log("получил", args); return "ok"; };
```

**Ведущий** — в консоли (подставьте имя игрока А):

```js
await game.users.getName("ИМЯ ИГРОКА А").query("ssl_tavern_games.spike", { secret: "tavern-spike-12345" });
```

- У игрока А в консоли «получил …», у ведущего вернулось `"ok"` — запросы работают.
- У игрока Б **ничего не появилось** — канал приватный, чужие кости действительно скрыты.
- У игрока Б появилось «УТЕЧКА» — сервер рассылает запросы всем. Тогда чужие кости скрыты только
  в интерфейсе; сообщите об этом, канал нужно будет заменить.

Заодно посмотрите у игрока А, сколько аргументов пришло в обработчик (`args`): если кроме данных
есть сведения об отправителе, проверку «чей это ход» можно будет сделать строже.

## 2. Кнопка «За стол» в меню токена

Правый щелчок по токену — справа в меню должна быть кнопка со стулом. Если её нет, в консоли:

```js
canvas.hud.token.element.querySelector(".col.right")
```

Вернулось `null` — пришлите, как называется правая колонка: `canvas.hud.token.element.innerHTML`.

## 3. Чек-лист партии

- [ ] Кнопка с кружкой на панели токенов открывает «Таверну» у ведущего.
- [ ] «Взять выделенные» сажает выделенные токены; токен игрока садит игрока.
- [ ] Партия каждой из шести игр доигрывается: игрок + бот + NPC под рукой ведущего.
- [ ] dnd5e: ставка снимается с листа (в том числе у NPC «из кошелька»), банк приходит победителю.
- [ ] Dice So Nice: кости катятся у всех; без него — стучат и перелистываются в окне.
- [ ] Перезагрузка страницы ведущего посреди хода бота — партия продолжается.
- [ ] Два стола одновременно.
- [ ] Обе темы; окно, вынесенное в отдельное окно браузера.
- [ ] Английский язык Foundry — модуль по-английски.
